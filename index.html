Android time tracking

Track hours with less page and less friction.

Clockr is a Kotlin Android app for offline-first hour tracking with a foreground-service timer, editable work entries, and a compact stats flow for pay-period visibility.

See screenshots GitHub repo

Current app attributes

  • Kotlin, Jetpack Compose, Room, and MVVM architecture.
  • Foreground timer flow with start and stop tracking.
  • Settings for default project label, pay rate, pay period, and work days.
  • Stats screen for pay-period totals and estimated earnings.

Core flow

  • Start work fast from the home screen.
  • Review and edit logged entries.
  • Check earnings without leaving the app flow.
